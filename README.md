# Project Work – Pagina Web per la divulgazione dei report di sostenibilità

Questo progetto è stato sviluppato nell’ambito del corso universitario di **Informatica per le Aziende Digitali**.

L'obiettivo del project work consiste nello sviluppo di una **pagina web realizzata con HTML e CSS** dedicata alla divulgazione delle attività di sostenibilità di un’impresa del settore primario e alla possibilità di scaricare i relativi report di sostenibilità.

## Impresa analizzata

Il caso aziendale selezionato è **Società Agricola Don Camillo S.c.r.l.**, organizzazione di produttori del settore ortofrutticolo italiano specializzata nella produzione e commercializzazione di:

- Melone Mantovano IGP
- Angurie
- Zucche
- Agrumi

L’impresa pubblica periodicamente documenti di rendicontazione relativi alle proprie attività ambientali, sociali ed economiche.

## Obiettivo della pagina web

La pagina web sviluppata ha lo scopo di:

- presentare sinteticamente le attività dell’impresa nell’ambito della sostenibilità
- rendere accessibili i principali contenuti ESG
- consentire il download diretto dei report di sostenibilità pubblicati dall’impresa

## Tecnologie utilizzate

Il progetto è stato realizzato utilizzando tecnologie web di base:

- HTML5
- CSS3

Non sono stati utilizzati framework o librerie esterne, al fine di mantenere il codice semplice, leggibile e facilmente replicabile.
